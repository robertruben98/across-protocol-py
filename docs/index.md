# across-protocol-py

Python client for the Across Protocol bridge API (suggested-fees, routes, deposit status). Sync + async, Pydantic v2.

## Install

```bash
pip install across-protocol-py
```

The distribution is `across-protocol-py`; the import package is `across_protocol`.

## Quick start

```python
import across_protocol
```

See the [API reference](api.md) for the full surface.
